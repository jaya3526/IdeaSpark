# IdeaSpark Node.js Project

This is a Node.js application that connects to a MySQL database for handling data in the **IdeaSpark** database.

## Prerequisites

Before running the project, ensure you have the following installed on your machine:

- **Node.js** 
- **MySQL** 
- **npm**

## Getting Started

### 1. Clone the Repository

Clone this repository to your local machine and add the required dependencies which are in package.json file.
